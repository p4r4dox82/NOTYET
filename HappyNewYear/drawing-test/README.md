# Three.js Drawing Test

This project demonstrates how to draw on a material using a brush in Three.js. The changes are reflected in real-time on a 3D model.

## Features
- Interactive drawing on a canvas.
- Real-time updates to the material applied to a 3D sphere.
- Simple Three.js setup.

## How to Run
1. Open `index.html` in a browser.
2. Use the mouse to draw on the canvas. The changes will appear on the sphere in real-time.

## Project Structure
- `index.html`: The main HTML file.
- `app.js`: Contains the Three.js logic and drawing functionality.

## Dependencies
- [Three.js](https://threejs.org/)
